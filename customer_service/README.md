1) Пользователь только что зарегестрировался
- Приходит событие из auth_service на создание пустой сущности
- Создается неактивированный неподтвержденный пользователь (т.е. пользователь не ввел данные профиля и пользователь не подтвердил свою личность с помощью KYC)

2) Пользователь получает свои данные
- Если у пользователя неактивирован аккаунт, то ему требуется ввести данные и подтвердить свою почту
- Если пользователь активирован, то он получае свли данные

3) Обновление данных
- Пользователь вводит данные и отправлят на АПИ

4) Подтверждение KYC для открытия счета
- Подтверждение данных
